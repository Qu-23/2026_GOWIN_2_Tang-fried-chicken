回传

「回传到电脑」会把 JSON 存到笔记本的 tools/captures/，文件名自动带时间戳。

板子回传的事件（蓝牙 → 笔记本 → 这里）

方式一：局域网中继（手机推荐）

笔记本上跑 python tools/bridge.py --serial COM5，它会打印两个网址。 手机连同一个 Wi-Fi，用手机浏览器打开 http://<笔记本IP>:8080/ 就是本页， WebSocket 地址会自动填好。

串口（笔记本上的板子）

串口列表来自 bridge.py，需要笔记本已经插上板子（或蓝牙已配对生成 COM 口）。

方式二：USB 直连（桌面 Chrome，无中继）

安卓 Chrome 没有 Web Serial，这个按钮只在电脑上有效。
