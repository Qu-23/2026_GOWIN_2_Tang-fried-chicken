# 当前控制协议

## 现有 UART 输入

名义波特率 115200，8 数据位、无校验、1 停止位。FPGA UART 时钟来自现有音频时钟，CLK_PER_BIT=14。
电平域及物理接线见 CST；USB Type-C 不能直接发送这种 TTL 波形。

二进制音符帧共 4 字节：`A5 cmd note velocity`。

- cmd.bit7：1 为按下，0 为松开。
- cmd.bit6：0 为音符，1 为控制帧。
- cmd.bits[1:0]：音色，本最终版使用 0 电钢、3 大提琴。
- cmd.bits[3:2]：音色变体，电钢 A 用 0，大提琴用 2。
- cmd.bits[5:4]：颤音档位，0 关闭；网页大提琴预设用 2。
- note：MIDI 音号 60..84；固件内部才转成 0..24 索引。
- velocity：力度 1..255；松开通常为 0。

示例（均为十六进制原始字节，非同名 ASCII 文本）：

| 动作 | 字节 |
| --- | --- |
| 电钢 C4 按下，力度 200，颤音关 | A5 80 3C C8 |
| 电钢 C4 松开 | A5 00 3C 00 |
| 大提琴 C4 按下，力度 140，变体 2，颤音 2 | A5 AB 3C 8C |
| 同一大提琴 C4 松开 | A5 2B 3C 00 |

同音高的两种音色需要各自发送匹配音色的松键帧。
控制帧位定义以 `fpga/snapshot/src/uart_rx.v` 的解析代码与 `pc/tools/bridge.py` 的打包函数为准，部分历史注释仍反映旧预设。

## 蓝牙文本

`N60,200` 按下，`O60` 松开。`S72` 设置速度并清空曲谱，`K72,1` 添加音号 72/1 拍，`P` 从头播放，`X` 停止；每条以换行结尾。
S/K/P/X 只传单旋律，最多 128 条，复位/断电失效。音色沿用上次蓝牙二进制 Note On，固定力度 200。
这些协议目前在已有 UART/蓝牙通路实现，尚不代表已实现 CH569 USB 端点协议。
