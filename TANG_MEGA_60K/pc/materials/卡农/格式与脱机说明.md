# 当前《卡农（片段）》导出

这里导出的是当前曲库中的简化旋律片段，共 41 条、48 拍，速度 72 BPM，谱面时长 40 秒。不是完整原曲。

## 网页 JSON

`卡农_网页曲谱.json` 与当前根目录、演示包和最终发布包中的 `song02.json` 完全一致。
`tempo` 为每分钟拍数；顶层 `notes` 中每项为 `[MIDI音号, 拍数]`，供旧格式及脱机导出使用。
`tracks` 是网页实际播放的声部列表；每个声部含 `wave`（0 电钢、3 大提琴）、`vari`（变体）、`vib`（颤音档位）、`gate`（按住时长占该音时值的比例）和 `notes`。
声部内每项为 `[MIDI音号, 拍数, 力度]`。例如 `[72,1,144]` 是 C5、1 拍、力度 144（本系统 1..255）。音号 0 表示休止；当前音域 60..84。
本曲只有一个大提琴声部，`wave=3, vari=2, vib=2, gate=0.96`。

## 板端 S/K 文本

`卡农_脱机主旋律.txt` 可导入网页，与网页“复制主旋律文本”的内容一致。
`卡农_串口加载并播放.txt` 末尾多一条 `P`，用于按行经蓝牙串口加载后开始播放。

```text
S72
K72,1
K71,1
K69,1
```

`S72` 设置 72 BPM 并清空原曲；`K72,1` 追加 MIDI 72、1 拍；`P` 从头播放；`X` 停止。`K0,1` 是 1 拍休止。通过串口工具发送时选文本模式，每行带 LF 或 CR/LF，并留出行间隔。

## 当前脱机范围

手机连接代理 → 曲谱 → 选择本曲 → 弹窗点“取消”查看选项 → 输入 `2` 推给 60K。加载结束后网页发送 `P`，FPGA 自己计时，可以关闭手机网页或断开代理，板卡继续播放。
此通路在最终固件启用，输入走 JDY-31 蓝牙 UART；USB 的二进制演奏通路不接收 S/K/P/X 文本。
曲谱最多 128 条，单旋律，存放于易失性板内存储；复位或断电后需要重传，不是写入 Flash 后永久保存。
文本不携带音色、逐音力度、gate 或多声部信息。固件以固定力度 200 播放，音色沿用播放开始前最后一条蓝牙二进制 Note On 指定的音色。
若要本曲以大提琴脱机播放，先在网页选择大提琴，实际按下并松开一个音，再下发本曲；只切换网页音色选择器不足以修改板端记忆。
当前网页的“主旋律已下发”提示表示发送流程结束，没有板端逐条接收确认。缓存与自主播放已通过 RTL 仿真，实板蓝牙下载仍待测试。
