# APDS-9960 接近/红外模块 FPGA 测试进度

- 更新时间：2026-11-03
- 板卡：小梅哥 ACG525（GW5A-LV25UG324ES / GW5A-25A，UBGA324）
- 工具：Gowin EDA V1.9.12.03、ModelSim ASE 10.5b（Intel FPGA 18.0 自带）
- 目标：用 FPGA 直接驱动 APDS-9960（I2C），读取接近值并用板载 LED 指示

---

## 1. 硬件连接

| 信号 | 板卡资源 | FPGA 引脚 | 说明 |
| --- | --- | --- | --- |
| clk | CLK_G 50 MHz | T9 | 系统时钟 |
| rst_n | KEY0 | B16 | 低有效复位 |
| led | LED0 | D14 | 指示：正常时 PWM 跟随 prox，异常时闪烁 |
| scl | 40P 扩展口 GPIO0 | **C17** | LVCMOS33，内部弱上拉已开 |
| sda | 40P 扩展口 GPIO1 | **C18** | LVCMOS33，内部弱上拉已开 |

模块侧：VCC→3.3V、GND→GND、SCL→GPIO0、SDA→GPIO1、INT 不接。
模块上的 "I2C pullup enable"（4.7k 到 VCC 的跳线/焊盘）**必须使能**。

模块基本参数：I2C 地址 `0x39`，ID 寄存器 `0x92` 应读回 `0xAB`，接近值寄存器 `PDATA=0x9C`。

---

## 2. 设计结构

原工程：`GOWIN\EXAMPLE\ACG525\ch4_led_flash_gao\`（目前仍在官方例程目录下，后续建议整体移到独立测试目录）

| 文件 | 作用 |
| --- | --- |
| `src/i2c_master.v` | 轮询式 I2C 主机：7 位地址、100 kHz、开漏；一次 `go` 完成"写一个寄存器"或"连读 N 字节"；带 ACK 检测与 `ack_err` |
| `src/apds9960_ctrl.v` | 控制器：读 ID 校验（失败每 100 ms 重试，支持热插拔）→ 写 7 条配置 → 每 20 ms 轮询 `PDATA`，输出 `prox[7:0]` / `near` / `sensor_ok` |
| `src/apds9960_top.v` | 顶层：LED 用 PWM（亮度∝prox）；`sensor_ok=0` 时约 3 Hz 闪烁 |
| `src/led_flash.cst` | 引脚约束（含 scl/sda 及备选方案注释） |
| `sim/apds_tb.sv` | 行为级 I2C 从机模型 + 自检 TB（ID=0xAB、PDATA=0x5A） |
| `sim/run_apds_sim.bat` | 一键跑 ModelSim 回归 |
| `build.tcl` | 一键综合+布局布线（`gw_sh build.tcl`） |

关键参数：`I2C_FREQ=100 kHz`、`POLL_MS=20`、`RETRY_MS=100`、`PROX_THRESHOLD=80`、`LED_ACTIVE_HIGH=1`。

初始化写入序列（对应 Arduino 库 `begin()`）：

| 序号 | 寄存器 | 值 | 含义 |
| --- | --- | --- | --- |
| 1 | 0x80 ENABLE | 0x00 | 全部关闭 |
| 2 | 0x81 ATIME | 0xFC | 积分时间 ≈11 ms |
| 3 | 0x8F CONTROL | 0x0D | PGAIN=8x、AGAIN=4x、LDRIVE=100 mA |
| 4 | 0x90 CONFIG2 | 0x11 | LED_BOOST=150% |
| 5 | 0x8E PPULSE | 0x87 | 16 µs × 8 脉冲 |
| 6 | 0x80 ENABLE | 0x01 | PON=1（等待 10 ms） |
| 7 | 0x80 ENABLE | 0x05 | PON=1 + PEN=1（再等 10 ms 后开始轮询） |

## 3. 已完成并验证

- **仿真（ModelSim）全部通过**：
  - ID 读回 `0xAB`；
  - 7 条配置寄存器写入值与上表一致（ENABLE 最终 0x05、CONTROL 0x0D、ATIME 0xFC、CONFIG2 0x11、PPULSE 0x87）；
  - `PDATA` 读回 `0x5A`，`prox=0x5A`、`near=1`、`sensor_ok=1`；
  - 输出 `==== ALL CHECKS PASSED ====`。
- **综合 + 布局布线通过**（GowinSynthesis + PnR）：
  - 顶层 `apds9960_top`，无错误；
  - 资源：377 逻辑单元（329 LUT + 48 ALU）、158 寄存器、0 latch；
  - 引脚核对：`scl → C17/2 IOR9[A]`、`sda → C18/2 IOR9[B]`，均 LVCMOS33 / Pull=UP；
  - 码流：`impl/pnr/led_flash.fs`（5.96 MB）。
- **仿真期间修掉一个实际 bug**：`i2c_master` 读事务的第一个地址相位曾错发成 `addr+R`，已改为"先发 `addr+W`+寄存器地址，寄存器 ACK 后再重复 START + `addr+R`"。
- 警告：`TA1132 'clk' was determined to be a clock but was not created`，因为工程没有 `.sdc` 时钟约束（对本设计无影响）。

## 4. 当前状态：上板未通

现象：下载码流后 **LED 以约 3 Hz 规律闪烁**，对应 `sensor_ok=0`，即 ID 读取或配置阶段一直失败（不是"检测到物体"的指示）。

已排除/待确认的易错点：

1. 确认下载的是 `impl/pnr/led_flash.fs`，**不是** `impl/pnr/ao_0.fs`（后者是早期 GAO 版 `led_flash` 的旧码流，下载后 LED 会约 1 Hz 慢闪）。
2. 判断闪烁类型：3 Hz 规律闪 = I2C 失败；1 Hz 慢闪 = 下错码流；亮度高频抖动 = 其实已通、prox 在刷新。
3. 模块上拉是否使能（下一步重点，见下）。
4. 接线：GND 是否接、SCL/SDA 是否接反、是否插在 GPIO0/GPIO1 两个脚上、模块 VCC 是否 3.3 V（不是 5 V）。
5. 若模块有独立 `VL`（红外 LED 电源）脚，需接 3.3 V；否则 ID 能读但 prox 恒为 0。

---

## 5. 下一步排查（按顺序）

1. **断电测电阻**：万用表量模块 SDA↔GND、SCL↔GND，应约 **4.7 kΩ**；OL 表示上拉未使能（插跳线帽/短接焊盘）。
2. **上电测电压**：总线空闲时 SCL、SDA 对 GND 均应约 **3.3 V**（这是"上拉是否有效"最直接的判据）；同时确认模块 VCC–GND = 3.3 V。
3. 若电气正常：可直接对调 SCL/SDA 试一次；再用示波器/逻辑分析仪看每 100 ms 是否有一串 100 kHz 时钟、第 9 个时钟 SDA 是否被从机拉低（ACK）。
4. 没有仪器时的两个备选方案：
   - 升级为**故障码闪灯固件**：1 下闪=地址无 ACK（电气）、2 下=ID 不为 0xAB、3 下=配置阶段失败；
   - 重建 GAO 配置，抓 `scl / sda / prox[7:0]` 波形定位。

## 6. 已知遗留问题

- `src/led_flash.rao`（GAO 配置）已设为禁用：顶层换成 `apds9960_top` 后，原配置绑定的 `led_flash/cnt` 不存在，若启用会报 `ERROR (EX0320)`。需要 GAO 时须按新顶层重建 `.rao`。
- `impl/pnr/` 下仍留有旧的 `ao_0.fs / ao_0.bin / ao_0.binx`，下载时注意别选错。
- 工程缺少 `.sdc`，时钟未约束（可选补 `create_clock -period 20`）。
- 代码目前只做"接近值"，手势（GFIFO 四方向差分）和 RGB/环境光尚未实现；`i2c_master` 已支持多字节连读，可直接扩展。
- 测试工程位于官方例程目录内，建议整体移到独立目录后再继续调试。
