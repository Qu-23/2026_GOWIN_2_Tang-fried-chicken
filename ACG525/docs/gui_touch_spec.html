状态交互: 单选组(音色/颤音/滑音/变体)点击即选中并高亮; 循环组(FX/R0/M3)点击切换数值; TS 切换测试模式(橙色); 和弦按住发 3 个 note_on、松开发 note_off; CL 全停; O-/O+ 对发送音符做 ±12 半音移调(钳位 C4..C6); LAMP 控制琴键底部照明 LED。 顶栏: TONE 当前音色+变体 / L=光强十六进制(光电感应维度) / E=I2C 诊断位 / TX 灯 / PLAY|TEST。
区域坐标 (x,y,w,h)标签动作 → 协议帧
音色 ×4(0/120/240/360, 24, 120, 88)EP PL BA CE本地锁存 cfg_wave=cmd[1:0], 下次 note_on 生效
颤音 ×4(0..180, 112, 60, 56)V0..V3本地锁存 cfg_vib=cmd[5:4], 逐音符生效
滑音 ×4(240..420, 112, 60, 56)G0..G3表情帧 cmd=0x40, note=0x80|gli<<2|vib
变体 ×3(0..120, 168, 60, 56)A B C本地锁存 cfg_ep=cmd[3:2]
效果器(180, 168, 60, 56) 循环 0-3FX OFF/REV/DLY/CHO效果器帧 cmd=0x40, note=sel|mix<<2|rev<<4
混响/干湿(240/300, 168, 60, 56) 循环R0-R2 / M0-M3同上, rev/mix 位段
八度 ×2(360/420, 168, 60, 56)O- O+发送前 note±12, 钳位 60..84
测试模式(0, 224, 60, 48) toggleTS控制帧 cmd=0x40, note=0x40|tst
和弦 ×3(60/120/180, 224, 60, 48)CM GM FM按下: C4+E4+G4 等 3×note_on(FIFO 顺序发); 松开: 3×note_off
照明(240, 224, 120, 48) toggleLAMP本地 GPIO → 琴键底部照明 LED (光电琴键的光源)
全停(360, 224, 120, 48)CL对当前活跃音发 note_off
